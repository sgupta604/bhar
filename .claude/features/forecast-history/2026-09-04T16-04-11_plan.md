## Architecture

### Summary

F6 is **contract-first, then two independent halves**. The §10 key set is locked in
`forecast/contract.py` **before** anything else exists, because the builder and the UI both encode
it and two authors guessing at a shared shape is the failure this pipeline exists to prevent.
`forecast/history.py` then reads the two parquets **read-only**, **imports**
`score.join.join_forecasts_to_obs` unmodified (which delivers the ±30-minute rule, `offset_min` on
every row, the never-interpolate rule and the 80 % floor already proven), adds the **per-date**
zero-match omission that `score.join` does not cover (it groups by `(model, lead_h)`, not by date),
applies `forecast.weights.load_fitted_weights`' label-matched vectors, and writes
`data/forecast_history.json` through a validate-then-`os.replace` path. The file is **committed**.
`backend/forecast_api.py` gets **zero edits** — adding `load_and_validate_history` to
`forecast/contract.py` lights the endpoint up through F4's per-call `getattr` seam. The UI extends
**F5's existing three frontend files** — no fourth file — with the day stepper, the per-day table
and the omitted-day list from design-target §1.6.

### The per-date omission, precisely

`join_forecasts_to_obs` returns only matched rows. The omission set is therefore:

```
dates_in  = { valid_time.dt.date (UTC) present in the INPUT forecast frame }
dates_out = { valid_time.dt.date (UTC) present in the MATCHED frame }
omitted   = dates_in − dates_out          # each recorded with its reason and its counts
```

`days` is built only from `dates_out`. A date in `omitted` is **absent from `days`** and present in
`meta.omitted_days` with `{date, reason, n_forecast_rows, n_matched_rows}`. It is never emitted with
`mae_f = 0`.

**Sharp edge for the synthetic fixture (Stream 3):** `join_forecasts_to_obs` *raises* when any
`(model, lead_h)` group falls below the 80 % floor. A fixture in which one date is fully unmatched
must therefore keep every group at or above 80 % overall — e.g. **10 dates, 1 fully unmatched → 90 %
matched per group**. A one-date fixture cannot exercise the branch; it trips the floor instead.

- **D-F6-2 — Six `meta` additions plus per-day `n_by_lead`, adopted.** Each is load-bearing:
