## 1. Architecture

### Summary

F5 shipped the panel shell; F3/F4 shipped the payloads. F7 adds **no file, no endpoint, no
contract field and no new metric**. It adds one **pinned prose block** and four renderers to
`frontend/forecast.js`, two host elements to `frontend/forecast.html`, a small CSS addition to
`frontend/forecast.css`, and **two pytest modules that are the actual deliverable** — because §6
lives or dies in the copy, and the copy is only checkable at source level in this project.

Everything the panel says is composed from payload fields. Nothing is typed. The panel makes exactly
one kind of statement — *what already happened, at this site, at this lead, over the scored window* —
and the tests exist to make a future edit that turns it into a claim about tomorrow fail loudly.

### Where the code goes, and why it matters mechanically

F6's region extractor slices `forecast.js` and `forecast.css` **from its banner to EOF**
(`region_from_marker(..., closer=None)`). The F6 banners are at **`forecast.js:881`** and
**`forecast.css:1096`**.

**F7's JS and CSS must be inserted BEFORE those lines** — JS immediately after `renderSkillShell`
(ends ~`:848`), CSS immediately after `.skill-weights-age .skill-weights-note` (ends ~`:1020`),
before `SECTION 3 — the stale treatment`. Appending at EOF would drop F7's code **inside F6's
region**, where `LEAD_LITERAL` (bans a bare `6|12|24`) and F6's region floors would then scan it.
This is the single highest-probability mechanical failure in the ticket and Task 1.1 probes it.

### Improvement tone and the clause that must agree with it — the fixture lie

§4's three lead sentences all read *"— better than the best single model (…)"*. On
`data/forecast.fixture.json` the 24 h blend is **worse** (9.99 vs GFS 8.88, `improvement_pct −12.5`).
A single "better than" template therefore **renders a falsehood on the fixture** while passing on
live data — the exact shape §15 bans.

**The comparison clause and the tone token are computed from one function, off the same D4
boundaries**, so they can never disagree:

| `improvement_pct` | State | Clause (`.skill-copy`) | `.skill-improve` tone |
|---|---|---|---|
| `> +0.05` | win | `— better than the best single model (<M>, <mae> °F) over the same period.` | D4 win token |
| `within ±0.05` | tie | `— level with the best single model (<M>, <mae> °F) over the same period.` | `--text-muted` |
| `< −0.05` | loss | `— worse than the best single model (<M>, <mae> °F) over the same period.` | `--danger` |

Boundaries and tokens are read from `.claude/features/demo-shell/design-target.md` §3 and **never
re-derived**. All three variants are byte-pinned. Loss renders at **identical** size, position and
weight to a win; only the tone token differs.

### Derivations — stated once, never re-derived, never typed

| Rendered | Derivation | live | fixture |
|---|---|---|---|
| lead label | `by_lead[].lead_h + '-hour lead'` | 6/12/24-hour lead | same |
| pairs per lead ("not 120") | `Math.round(n_test * (train_days + test_days) / test_days)` | 120 | 132 |
| runs per day | `pairs / window.days`; integral ⇒ `countWord(n)` capitalised, else the pinned `Several initialisations a day…` variant | 4 → "Four" | 4.4 → "Several" |
| independent days | `by_lead[].independent_days_approx` | ~30 | ~33 |
| MAE in prose | `fmt(v, 2)` | 1.92 | 5.55 |
| MAE in cells | full payload precision | 1.9173 | 5.55 |
| `improvement_pct` | `fmt(v, 1, true)` — real U+2212, never `Math.abs`, never clamped | +9.0 | −12.5 |
| 12 h "coincidence" clause | renders iff `blend_mae ≤ in_sample && (in_sample − blend_mae) < 0.01` — **never** `lead_h === 12` | 12 h only | none |
| weight chips | forward row whose `weights_fitted_at_lead_h === lead_h`; canonical HRRR·GFS·NAM·NBM from `meta.models_included`; **`0.0` rendered, never dropped**; **no matching row ⇒ chips omitted entirely** | present | present |
| cross-link boundary | first slot with `is_extrapolated_lead === true` → its `lead_h`; none ⇒ sibling omitted | 27 | 27 |
| realized MAE | `mean(|error_f|)` **pooled over `days[].entries[]` at that lead** — **never** the mean of `days[].mae_f`, which gives 1.8958/2.2713/2.0052 and is wrong | 1.83/1.97/2.05 | n/a |
| archived-day count | `history.days.length` | 32 | n/a |
| fitted-day count | `weights_source.split.train_days` | 20 | n/a |

`.skill-basis` renders `skill.basis` through a small enum→prose map **with fallback to the raw
value** (an unknown basis renders verbatim rather than vanishing), then `skill.note` verbatim, then
README C2's sentence. The fixture's note begins *"FABRICATED. Nothing here was measured…"* and must
render as-is.

## 6. What the guard CANNOT catch — carry this into SUMMARY verbatim

A guard that overclaims is worse than none. This one is **source-level, by design**, and:

1. **It never reads the rendered DOM.** There is no JS test runner in this project (SPEC §13). Correct
   source with a broken render passes. Task 7.2's snapshot is evidence, never a gate.
2. **It cannot catch a claim phrased in words nobody blacklisted** ("we'd be surprised by more than
   two degrees"). Layer 2's byte-pinning is the real defence; Layer 3 is a tripwire for drift.
3. **It cannot police future server payloads** — only the two committed ones. The value-level
   `skill.note` ban in `forecast/contract.py` remains an open, separately-queued quickfix.
4. **It cannot see CSS `content:` prose unless the F7 CSS region is scanned** — which is why all three
   files are scanned, as F5 and F6 do.

## 9. Key Decisions

1. **Realized shown with the caveat, not suppressed** — suppressing a flattering number is itself
   selection (§15). The caveat sentence, naming the different day set and the 20 fitted days included,
   is the honest instrument.
2. **Pooled `error_f`, never the mean of daily `mae_f`** — days carry unequal row counts; the two
   differ by up to 0.30 °F and mixing them would be a third, unlabelled number.
3. **Three comparison-clause variants, computed off the same D4 boundaries as the tone** — a single
   "better than" template passes on live data and lies on the fixture. Clause and tone can never disagree.
4. **F7 code goes before the F6 banners**, so F6's tail-anchored region slice is unchanged.
5. **Containment first** — without it, layers 2–4 scan a subset of the copy and report the same green.
6. **§4 governs over §1.5** on `.skill-extrapolated`; the cross-link is a sibling (settled decision 4).
7. **The baseline is 1208 + 1 known failure**, not 1209, and the gate is restated accordingly.
