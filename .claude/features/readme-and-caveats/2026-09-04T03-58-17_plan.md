## Architecture

### Summary

T6 produces exactly one artifact: a full rewrite of `README.md`. There is no code, no schema, no
test. The only architecture question is **sequencing**, and it is decided: the README is written in
two passes so that the writing pass does not wait on T5.

**Pass A (now, T5-independent):** every heading, every caveat, every mechanism, every command, every
non-result fact — all of it already exists in the repo, the SPEC, the spike, and the four SUMMARYs.
Every place a T5 number belongs gets a literal `TBD-FROM-T5` token.

**Pass B (after T5 is green, ~10 min):** the thirteen values are copied out of the real
`data/results.json` in one pass. The ticket's completion gate is mechanical:

```bash
grep -n "TBD" README.md    # must print nothing
```

That gate is why D2 matters. It converts "no invented numbers" from a promise into a check, and it
takes T6 almost entirely off T5's critical path — which is the whole point, because T5 is the thing
that might slip and the deadline is 07:30.
