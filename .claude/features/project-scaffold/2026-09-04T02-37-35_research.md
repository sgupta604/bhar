## Patterns to Follow

- **Manifest mirrors reality, exactly.** The venv is the source of truth tonight; `pyproject.toml`
  is written *from* `uv pip list`, not from memory or from what looks tidy.
- **Assert loudly, cheaply, early** (SPEC §4, §10; spike F9). The scaffold's own test is an
  assertion that the environment is what the spike said it was.
- **Contract-first** (SPEC §7, README "Key Design Decisions"). T1 creates the directories that the
  §7 `results.json` contract will flow through: `score/` writes it, `data/` holds it, `backend/`
  serves it, `frontend/` renders it.
- **Every ticket ends green and committed** (SPEC §9). T1's deliverable is a green `uv run pytest`,
  not a set of files.
- **Timestamped feature docs**, `YYYY-MM-DDTHH-MM-SS_<phase>.md`, matching the spike filename.
- **Kebab-case feature names, `feat/` branch** (CLAUDE.md rules 8–9).

## Patterns to Avoid

- **Do not re-provision.** `uv venv`, `uv pip install pandas ...`, `brew install uv` are all
  forbidden re-work and each one risks un-validating the GRIB path (SPEC §17, spike F12).
- **Do not use unpinned/loose version ranges** for the GRIB stack. A resolver that "helpfully"
  upgrades `eccodes` throws away the one result that was proven live tonight.
- **Do not add a `[build-system]`** and make this a distributable package. Nothing installs `bhar`.
- **Do not add mypy/pyright.** Not required by SPEC §13, not installed, and a type-checker's first
  run on empty modules is pure cost at 03:00.
- **Do not use `ruff format --check`** in the Commands block — formatting drift would fail `/test`
  on style while the code is correct, violating SPEC §9's "never leave the tree broken."
- **Do not follow BRIEF §13's flat filenames** (`fetch_forecasts.py`, `score.py`, `demo.html`).
  SPEC §6's package layout supersedes it, and SPEC precedence is explicit.
- **Do not create an npm/node frontend toolchain.** No bundler, no `package.json` — SPEC §15
  decision 14's "no container / no extra toolchains on the night it has to work" applies here too,
  and a build step would need a Build command that currently, correctly, does not exist.
- **Do not scope-creep into T2–T5.** `fetch/`, `score/` and `frontend/` ship as empty packages.

the acceptance floor, and an undeclared environment is unreproducible the moment anything is
